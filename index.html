ABOUT

关于我

业务理解 × 工程交付 × 数据治理 × 组织采用，是我做 FDE 的工作边界。

我是 阁主，一名从业务现场走到系统交付的 FDE 工程师。我的工作不是替团队“做一个工具”，而是把复杂问题整理成能被业务持续使用的能力。

业务视角：长期在销售、电商、运营与客户服务场景中做实操与管理，能先理解利润、效率、协同和风险，再讨论该不该上 AI、该从哪里开始。

工程视角：覆盖多 Agent、知识库、工作流自动化、Python / Node.js 应用、ERP / API 集成与私有化部署；重视用合适的方案解决问题，而非堆叠技术名词。

治理视角：系统从设计阶段就考虑数据口径、权限边界、审计留痕、异常流程与组织推广，让交付不止停在演示环境。
